== Close the Loop: Automatically Remediate Found CVEs

Module 2 wired up the EDA side so that Satellite's webhook reaches a
running rulebook. So far, that rulebook only logs the event. In this
module you'll extend it to actually *do* something useful: whenever a
remote execution job succeeds on a host, AAP will run
`vulnerability_remediation.py` (from the `vulnerability-package-finder`
project) against Satellite, scoped to that host, and install whatever
RPMs are needed to fix the CVEs it finds - closing the remediation loop
end to end.

`rhel1.lab` and `rhel2.lab` already have a handful of deliberately
vulnerable packages installed (seeded during lab setup) so you have
real CVEs to remediate.

.Step 1 - Self-host the vulnerability finder + remediation playbook
[%collapsible]
=====
Click on the tab labelled `aap1.lab terminal` and log in as `root`.

This reuses the same self-hosted-git-repo pattern from Module 2, and the
*same* deploy key you already generated there
(`~/.ssh/eda_project_deploy_key`) - no need to create a new one.

[source,bash,role="execute"]
----

fi

mkdir -p ~/vulnerability-remediation && cd ~/vulnerability-remediation
if [ ! -d .git ]; then
  git init
  git remote add controller ssh://aap1-user@localhost/home/aap1-user/git/vulnerability-remediation.git
fi
git config user.name "aap1-user"
git config user.email "aap1-user@aap1.lab"
'

Now write the Execution Environment `Containerfile`:

[source,bash,role="execute"]
----
sudo -u aap1-user bash -c '
cat > ~/vulnerability-remediation/Containerfile <<'"'"'EOF'"'"'

# vulnerability_remediation.py'"'"'s `#!/usr/bin/env -S uv run --script`

Next, write the remediation playbook, `find_and_remediate.yml`. It runs
the finder script scoped to the host that triggered the webhook
(`--host {{ host_name }}`), collects every package the report says is
needed on that host, then installs them:

[source,bash,role="execute"]
----
sudo -u aap1-user bash -c '
cat > ~/vulnerability-remediation/find_and_remediate.yml <<'"'"'EOF'"'"'
---
- name: Find CVE remediations for the affected host
  hosts: localhost
  connection: local
  gather_facts: false
  tasks:
    - name: Run vulnerability_remediation.py scoped to the affected host
      ansible.builtin.command:
        cmd: >-
          python3 vulnerability_remediation.py
          --satellite https://satellite.lab
          --username {{ satellite_username }}
          --host {{ host_name }}
          --insecure
        chdir: "{{ playbook_dir }}"
      register: scan_result
      changed_when: false

    - name: Parse the JSON report
      ansible.builtin.set_fact:
        remediations: "{{ scan_result.stdout | from_json }}"

    - name: Collect every package that needs installing on this host
      ansible.builtin.set_fact:
        packages_to_install: >-
          {{ remediations
             | selectattr("packages_to_install_on_host", "defined")
             | map(attribute="packages_to_install_on_host")
             | select("truthy")
             | sum(start=[]) }}

    - name: Show what will be installed
      ansible.builtin.debug:
        msg: >-
          {{ packages_to_install if packages_to_install
             else "No remediation packages found for " + host_name }}

    - name: Hand the affected host + package list to the next play
      ansible.builtin.add_host:
        name: "{{ host_name }}"
        groups: affected_hosts
        packages_to_install: "{{ packages_to_install }}"

- name: Install the fixed packages on the affected host
  hosts: affected_hosts
  become: true
  gather_facts: false
  tasks:
    - name: Install/upgrade each package that remediates a found CVE
      ansible.builtin.dnf:
        name: "{{ item }}"
        state: present
      loop: "{{ hostvars[inventory_hostname].packages_to_install }}"
      register: install_results
      when: hostvars[inventory_hostname].packages_to_install | length > 0

    - name: Show what changed
      ansible.builtin.debug:
        msg: "{{ item.item }}: {{ '"'"'installed/upgraded'"'"' if item.changed else '"'"'already up to date'"'"' }}"
      loop: "{{ install_results.results | default([]) }}"
      when: install_results.results is defined
EOF
'
----

[NOTE]
====
This module intentionally does *not* ship a full copy of
`vulnerability_remediation.py` inline. It's a large, actively-developed
script - grab the latest version from the `vulnerability-package-finder`
project and place it at
`~/vulnerability-remediation/vulnerability_remediation.py` on `aap1.lab`

a shared drop location) works - the important part is that the file
ends up in that repo directory before Step 1's `git add`/`commit`/`push`
below.
====

curl -sk -u "$CTRL_AUTH" "$CTRL_API/jobs/$JOB_ID/stdout/?format=txt" | tail -60
